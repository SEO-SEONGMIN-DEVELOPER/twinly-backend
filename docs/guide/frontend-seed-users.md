# 시드 유저 정보 (FE)

stage / local 에 미리 들어있는 테스트용 유저 20명의 정보입니다. 접속 정보·인증 규칙 등 나머지는 [frontend-stage-guide.md](./frontend-stage-guide.md) 를 보세요.

## 1. 어떻게 들어가는가

- 앱 기동 시 `PersonaSeeder` 가 채웁니다. **`local`, `stage` 에서만 동작하고 prod 에서는 동작하지 않습니다.**
- 이메일 기준으로 이미 있으면 건너뛰므로, 배포를 여러 번 해도 중복 생성되지 않습니다.
- 사람이 회원가입 플로우를 탄 게 아니라 **DB에 직접 꽂힌 유저**입니다. 아래 3절의 "시드에 없는 것"을 꼭 확인하세요.
