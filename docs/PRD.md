# 1. 문제 정의
## 타겟 사용자
- 이성 교제를 원하는 사람 중 
- 이성을 만날 기회를 얻고 싶은 사람 중
- 외부 활동을 못하거나 안하는 사람 중
- 데이팅 앱을 안 쓰고 있는 사람 중
- (1) 사회적 인식 때문에 안 쓰는 사람 (2) 신뢰성 때문에 안 쓰는 사람

---

# 2. 해결 방안
## 페인포인트 해결
### 부정적인 사회적 인식
- 브랜딩: 메타버스, 게이미피케이션 요소를 넣고 가벼운 디자인을 적용하여 일반적인 매칭 앱과 다르게 좀 더 가볍고 재밌게 느껴지게 한다. 
### 신뢰성
- 대학생끼리만 매칭되게 함으로써, 동질감을 통해 신뢰성을 향상한다.

## 기능 요구사항
### 요약
- 유저의 페르소나가 주입된 에이전트들이 가상 세계에 살아가다가 호감도가 일정 기준 이상이 되면 실제 유저 간 채팅방이 생성된다.

---

# 3. 비목표
- 결제/유료화는 하지 않는다.

---

# 4. 성공 지표
1. 자신의 페르소나가 주입된 AI Agent가 자신과 비슷하다고 느낀다.
2. 앱 내 매칭이 되었을 때, 시뮬레이션 결과에서 나타나는 상대방과의 성격 적합성이 실제와 유사하다.
3. 매칭앱이 아니라 재밌는 게임처럼 느껴진다.
